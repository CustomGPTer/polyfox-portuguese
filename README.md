# PolyFox Portuguese

PolyFox Portuguese is a free Portuguese course for Android, from the first word to level C2. Spoken audio, speaking checked on the phone, conversations, stories, verb tables and level exams. No adverts, no account, no internet.

Website: https://customgpter.github.io/polyfox-portuguese/
